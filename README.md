# Gargy Poddar — Portfolio Website

A responsive, single-page portfolio website built from the supplied 20-page portfolio PDF.

## Run locally
1. Extract the ZIP.
2. Open the `gargy-poddar-portfolio-website` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build step or package installation is required.

## Files
- `index.html` — content and page structure
- `styles.css` — responsive styling, typography, animations
- `script.js` — mobile navigation, scroll reveal, portfolio filters and image viewer
- `assets/` — optimized images rendered from the supplied portfolio PDF

## Deploy
- **Netlify:** drag the extracted project folder into Netlify Drop, or connect the folder's GitHub repository.
- **Vercel:** import the GitHub repository and use the default static site settings. No build command is needed; the output directory is the project root.

## Before publishing
- Confirm Gargy's approval to publish the contact details and portfolio images.
- Replace the rendered PDF page visuals with original high-resolution campaign assets if available.
- Add LinkedIn / Instagram links if the client wants them displayed; the supplied PDF did not include their URLs.
